1. 本包基于 2026年9月21日的 103 款产品版本，包含 I-规格吸头的包装信息。请先确认正式站具有相应完整网站文件。若正式站更旧，或 IT 独立修改过这 3 个代码文件，请先比对合并，勿直接覆盖独立改动。

3. 解压本次更新包，在包含 SHA256SUMS.txt 的目录校验文件。macOS 可用 shasum -a 256 -c SHA256SUMS.txt；Linux 可用 sha256sum -c SHA256SUMS.txt。4 个文件均应校验通过。

### 上传并刷新缓存

4. 将 site/ 下 4 个文件按原目录层级复制到现有官网根目录，覆盖同名文件。不要把 site/ 文件夹本身作为网站路径，不要删除其他文件。优先在发布目录准备好全部文件后统一切换；逐项上传时按图片、CSS、JS、HTML 的顺序操作。
