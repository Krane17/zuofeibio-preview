1. 确认基线。本包适用于已完成 2026 年 9 月 20 日更新的完整官网。部署前将上述 3 个已有文件与现网比较；如 IT 另有改动，先合并差异，不能直接覆盖。未完成此前更新时，先补齐旧版依赖。

2. 备份现网。将 products/index.html、assets/catalog.js、assets/site.css 一并备份到网站公开目录之外。记录备份位置、发布人员及时间；保留现网表单配置与其他资源，不做全站覆盖。

3. 校验交付包。解压后进入 zuofeibio-update-20260921 目录，运行下列对应命令，4 个站点文件应全部通过。release.json 记录固定来源提交、路径转换和校验值。

```bash

# macOS
shasum -a 256 -c SHA256SUMS.txt
```

4. 在完整官网测试副本中验证。先将 site/ 的 4 个文件合入测试副本，通过 HTTP 或 HTTPS 访问。增量包不能独立运行，不要双击 HTML 或使用 file:// 打开。

## 5 回退与故障处理

上线异常时，一并恢复部署前备份的 products/index.html、assets/catalog.js 和 assets/site.css，再刷新 CDN 与浏览器缓存。若基线为 9 月 20 日版本，应恢复为 102 款产品、5 款试剂耗材；自动化产品 9 款、常规仪器 88 款不变。新增 PNG 可暂留服务器，不再被旧目录引用，不必删除；后端和表单配置不回退。
